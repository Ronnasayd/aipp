# Troubleshooting

| Symptom                                                                                                  | Cause                                                                                                                           | Fix                                                                                                                     |
| -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Missing `.specs/features/{TAG}/checks.md`, or `validate_checks.py` red                                   | Feature never finished planning                                                                                                 | Report it and stop -- run `sd-lean-planning` first                                                                      |
| No matching tag in `.taskmaster/tasks/tasks.json`                                                        | Feature was never registered, or tag name mismatch                                                                              | Run `sd-insert-taskmaster` first, or proceed without sync if the user doesn't want tracking                             |
| `check_proofs.py` exits non-zero with `**Tree**: dirty` naming `.taskmaster/tasks/tasks.json` or `docs/` | A sync or docs change was left uncommitted; only `.specs/` is exempt                                                            | Commit it, then run `check_proofs.py` again                                                                             |
| `validate_verification.py`: `proofs.md was written at <sha> and HEAD is <sha>`                           | A commit landed after the last `check_proofs.py`, even one touching only `.specs/`, docs or `tasks.json`                        | Run `check_proofs.py` again at `HEAD` (with `--mutations` if the Verifier wrote them), then the gate                    |
| `set_task_status` returns `Expecting value: line 1 column 2 (char 1)`                                    | Comma-separated ids through mcp-manager; also seen once on a single id, the first call against a project, which changed nothing | One id per call. Retry a failed single id, then confirm with `get_tasks`                                                |
| Slice task is `done` but one of its subtasks is `pending`                                                | Setting the parent does not cascade to its subtasks                                                                             | Sync every check subtask individually, then the slice                                                                   |
| `set_task_status` returns success but tasks.json unchanged                                               | `tag` param omitted from the call                                                                                               | Always pass `tag`                                                                                                       |
| Running `sd-insert-taskmaster` again reset every status                                                  | `merge-tasks.py` replaces the whole tag                                                                                         | Don't re-register a started feature; add appended checks with `add_subtask`, then re-sync what `checks.md` shows closed |
| Taskmaster shows `done` but the Verifier later flags that check                                          | Sync happened at the slice's proofs, before the end-of-run Verifier                                                             | Revert the subtask and its slice to `pending`, re-sync to `done` with the fix (see Status mapping in SKILL.md)          |
| Taskmaster and `checks.md` disagree about what's closed                                                  | Tag edited by hand, or a previous run didn't sync                                                                               | Taskmaster is a mirror: `checks.md`, `proofs.md` and git history decide, never the tag                                  |
