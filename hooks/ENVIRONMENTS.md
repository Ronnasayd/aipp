# Hooks — Environment Variables

Env vars read by scripts in `hooks/scripts/`. All optional unless noted.

| Variable                        | Script                                                         | Default                                                                         | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CLAUDE_PROJECT_DIR`            | `protect_branches.py`, `protect_files.py`, `smart_approve.py`  | `os.getcwd()`                                                                   | Project root. Set by Claude Code itself; stable for the whole session.                                                                                                                                                                                                                                                                                                                                                                             |
| `CLAUDE_SETTINGS_PATH`          | `smart_approve.py`                                             | `$CLAUDE_CONFIG_DIR/settings.json`                                              | Global settings.json path override.                                                                                                                                                                                                                                                                                                                                                                                                                |
| `CLAUDE_PROJECT_DIR`            | `skill_activation.py` (required), `checklist_context_watch.py` | none (`skill_activation.py` raises `KeyError` if unset)                         | Root used to locate `.claude/skills/`.                                                                                                                                                                                                                                                                                                                                                                                                             |
| `CLAUDE_TRANSCRIPT_PATH`        | `session_end.py`                                               | none                                                                            | Fallback transcript path when stdin JSON has no `transcript_path` (backwards compat).                                                                                                                                                                                                                                                                                                                                                              |
| `CLAUDE_PACKAGE_MANAGER`        | `utils.py` (`_get_runner_from_package_manager`)                | inferred from `package.json` `packageManager` field, else `npx`                 | Force package-manager runner (e.g. `pnpm`, `yarn`).                                                                                                                                                                                                                                                                                                                                                                                                |
| `PROTECTED_BRANCHES`            | `protect_branches.py`                                          | `main,master,develop,homolog`                                                   | Comma-separated override of protected branch names.                                                                                                                                                                                                                                                                                                                                                                                                |
| `PROTECT_FILES_EXTRA_ALLOWED`   | `protect_files.py`                                             | none                                                                            | Comma/semicolon-separated extra glob patterns allowed past the file-protection hook. A bare path with no glob chars (`*?[`) gets `/**` appended automatically. Still subject to `PROTECTED_PATTERNS` (e.g. `.env`, `.pem`, `secrets/**`) — this only waives the outside-project check, never secret protection. Must be exported **before** launching Claude Code — the hook process doesn't inherit vars `export`ed from inside a Bash tool call. |
| `SMART_APPROVE_VERBOSE`         | `smart_approve.py`                                             | disabled                                                                        | `1`/`true`/`yes` enables verbose approval-decision logging.                                                                                                                                                                                                                                                                                                                                                                                        |
| `JSON_COLORIZE`                 | `log_hooks.py`                                                 | disabled                                                                        | If set (truthy), pretty-print/colorize logged JSON payloads instead of raw dump.                                                                                                                                                                                                                                                                                                                                                                   |
| `TMUX`                          | `dev_server_tmux_check.py`                                     | none                                                                            | Standard tmux env var; presence + valid socket path detects tmux session.                                                                                                                                                                                                                                                                                                                                                                          |
| `STY`                           | `dev_server_tmux_check.py`                                     | none                                                                            | Standard GNU screen env var; presence detects screen session.                                                                                                                                                                                                                                                                                                                                                                                      |
| `JEST_COVERAGE_CMD_INCREMENTAL` | `jest_coverage_incremental.py`                                 | `NODE_ENV=test node_modules/.bin/jest --passWithNoTests --runInBand`            | Override base runner command only. `--findRelatedTests <rel_path> --coverage --coverageDirectory=<dir> --collectCoverageFrom=<rel_path>` are always appended after it.                                                                                                                                                                                                                                                                             |
| `JEST_COVERAGE_CMD_FULL`        | `jest_coverage_session_end.py`                                 | `NODE_ENV=test node_modules/.bin/jest --coverage --passWithNoTests --runInBand` | Override full-project jest command run at session end. Plain string, no template substitution.                                                                                                                                                                                                                                                                                                                                                     |
| `OUTPUT_TRUNCATE_THRESHOLD`     | `utils.py` (`truncate_large_output`)                           | `2000`                                                                          | Max chars before tool output is truncated in hook logs/context.                                                                                                                                                                                                                                                                                                                                                                                    |
| `JSCPD_THRESHOLD`               | `utils.py`                                                     | `10`                                                                            | Duplication % threshold for jscpd lint gate.                                                                                                                                                                                                                                                                                                                                                                                                       |
| `JSCPD_MIN_LINES`               | `utils.py`                                                     | `15`                                                                            | Min lines for a jscpd duplicate match.                                                                                                                                                                                                                                                                                                                                                                                                             |
| `CLAUDE_CODE_SESSION_ID`        | `utils.py` (`get_hooks_logger`)                                | `""`                                                                            | Session id tag included in hook log lines. Set by Claude Code itself.                                                                                                                                                                                                                                                                                                                                                                              |
| `MD_LANGUAGE`                   | `md_language_check.py`                                         | `English`                                                                       | Expected language for markdown content checked by the hook.                                                                                                                                                                                                                                                                                                                                                                                        |
| `QUESTION_TOOL_LANG`            | `question_tool_enforcer.py`                                    | `""`                                                                            | Language hint used when enforcing use of the question tool.                                                                                                                                                                                                                                                                                                                                                                                        |
| `AI_PROJECT_DIR`                | `start_context.py` (`disabled_mcp_servers`)                    | none (section skipped if unset)                                                 | Enables rendering the "disabled MCP servers" section by reading `$CLAUDE_CONFIG_DIR/.claude.json`.                                                                                                                                                                                                                                                                                                                                                 |
| `AI_MEMORY_PROJECT_STRATEGY`    | `start_memory_rules.py`                                        | forced to `repo-root`                                                           | Set (not read) before invoking the ai-memory CLI subprocess, forcing repo-root project resolution.                                                                                                                                                                                                                                                                                                                                                 |
| `PROTECT_FILES_MCP_ALLOWLIST`   | `protect_files.py`                                             | `""`                                                                            | Colon/comma/space-separated MCP server names exempt from path-protection checks.                                                                                                                                                                                                                                                                                                                                                                   |
