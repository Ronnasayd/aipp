## When starting a new agent/sub-agent, make sure to follow these guidelines:

- The agent must be instructed to communicate using `ultracave`: fragments, one word when one word is enough, each fact once. Code, paths, commands, errors, negations and numbers stay verbatim.

- The agent must have sufficient context to perform its task.

- Choose the agent model best suited to the task.

- Must not include any information regarding Claude or any agent in commits
